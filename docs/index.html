Docs Image Copy as PNG

Copy a selected image from Google Docs as a standard PNG clipboard item for pasting into compatible websites and applications.

How it works

  1. Select one image in a Google Docs document.
  2. Press Ctrl+C.
  3. Paste into your destination with Ctrl+V.

The selected image is processed locally in Chrome. It is not uploaded, retained, tracked, or shared.

Open and focused

The extension has one purpose, no advertising or analytics, and no remotely loaded code. Its source is public for inspection and contribution.
