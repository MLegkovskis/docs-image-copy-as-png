# Privacy Policy for Docs Image Copy as PNG

Last updated: 8 November 2026

Docs Image Copy as PNG handles website content consisting of one selected Google
Docs image and its HTML clipboard representation. It reads this content only
after the user copies in a Google Docs document or explicitly activates the
extension. It converts the selected image locally to PNG and writes the PNG back
to the clipboard.

This content is processed transiently in the user's browser. It is not sent to
the developer or any third party and is not retained after conversion. The
extension does not sell or share user data. It has no analytics, advertising,
accounts, tracking, remote code, or extension-owned servers.

The extension runs only on Google Docs document pages. Clipboard permissions
are used solely for the user-facing image-copy conversion described above.

The use of information received from Google services adheres to the Chrome Web
Store User Data Policy, including its Limited Use requirements. User data is
used only to provide the extension's single clipboard-conversion purpose. It is
not used for advertising, profiling, creditworthiness, or unrelated purposes,
and no human reads the processed content.

Questions about this policy can be submitted through the project's
[GitHub Issues](https://github.com/MLegkovskis/docs-image-copy-as-png/issues).
